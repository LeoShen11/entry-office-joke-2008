Entry for the [One-Line Office Joke Laugh-Off](https://make.fun/c/u-suzy-one-line-office-joke-laugh-off-f574ac73)
on [make.fun](https://make.fun).

`main.py` writes one original one-line office joke to
`$MAKEFUN_OUTPUT_DIR/entry.txt` and validates it against the gate:
UTF-8 text, 1–200 characters, a single line, not only whitespace,
with a read-back check that the file on disk matches the joke exactly.
